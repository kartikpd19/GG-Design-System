# @goodgame/icons

SVG icons for the Good Game Design System, exported as React components.

> **Status:** not published yet (`"private": true`). The icon set hasn't been exported from Figma. Until then this package has no icons and no npm release.

## Planned usage

```tsx
import { Close } from "@goodgame/icons";

<Close size={16} aria-hidden />;
```

Icons inherit `currentColor` and default to `var(--icon-color)` when placed inside Good Game components.
