# Border radius

- **Small:** a subtle roundness for forms, buttons, checkboxes, selected marks and tooltips, giving a gentle, approachable look.
- **Medium:** a more noticeable curve for dropdowns, popovers, attention boxes and updates.
- **Large:** a pronounced roundness for popups, so they stand out while staying friendly.
