# Border radius

## The border radius scale

**Small:** This subtle roundness can be applied to forms, buttons, check boxes, selected marks, and tooltips to create a gentle, approachable look.<br />
**Medium:** A more noticeable curve, ideal for dropdowns, popovers, attention boxes, and updates, which enhances interactivity without being overwhelming.<br />
**Large:** This pronounced roundness suits popups, making them stand out while maintaining a friendly appearance.
