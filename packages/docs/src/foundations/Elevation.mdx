# Elevation

Shadows express the level of elevation between surfaces. Use them consistently: items with the same shadow can't occupy the same space.

> **Not mapped yet.** The Figma Elevation page defines four levels. Their shadow values haven't been imported into `@goodgame/style` yet, so no elevation tokens exist in code.
